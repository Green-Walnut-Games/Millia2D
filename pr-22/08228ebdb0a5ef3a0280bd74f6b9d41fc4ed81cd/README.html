Millia2D Game Engine

Millia2D is a small game engine framework, focused on providing great APIs to make games focusing on large numbers of entities and agents easier.

Key features:

  • easy to use debugging telemetry
  • simple to grasp World Actor Component architecture

Throughout the project, I will be looking at implementing various methods of helping create large-scale simulations. My current up-to-date research can be found here.

Usage

The first step is to create a game class inheriting from MilliaGame, then instantiating your class from wherever you want to use Millia2D.

For more tutorials or information, visit the docs or the samples.

Installation

To install Millia2D, add the latest nuget package to your project:

dotnet add package Millia2D
