Benchmark Game

The benchmark game will need to be simple enough for me to have enough time to program in 3 engines, but also have enough complexity to allow the game to perform heavy calculations to take advantage of Millia2D's capabilitys, or any research I have found.

Ideas

Space station empire - simulate different companies starting on different stars, colonizing the universe - semi-colony builder, kind of like 4X Foundations - new stars would spawn on the edge - able to build/purchase stations around stars - each station may have its own population of people, with needs and wants Why it would work:

  • late game, could have hundreds of stations interacting with each other
  • two systems: population and commerce
    • population would need every person having their own routines/jobs/families
    • commerce would handle inter-station trading and migration

Alien invasion game - start with a tiny settlement in a world invaded by aliens. Expand whilst more and more aliens attack. - colony builder/tower defense - colonist system and alien system

World wide colony game - create different colonies throughout the world, each one having different resources/purpose - similar to rimworld - each colony would interact with each other, trade, etc.

War Toy - simulate a grand war on a large battlefield - place squadrons of soldiers, tanks - place settlements/supply points - create trade routes - game simulates the outcome and shows result

Mega Space Ship - conquer planets with your warship - start small with only your own ship - start gathering your fleet of ships from each planet/station you conquer - ships battle other AI's fleets - how far can you get?

Solar System Defense - defend solar system against alien invaders - setup phase, then action phase - setup you place depots, give ship orders - each action phase will have a specific entry into the solar system - each action phase will be harder - place buildings/stations throughout universe - each action phase acts like a mini grand strategy game, with resources being able to decrease during the turn via things like ship upkeep, people on ships to be individually tracked?, alien ships acting completely differently and potentially trying to expand and set up bases themselves.
